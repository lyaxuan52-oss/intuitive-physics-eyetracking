# Data Layout

## Directory overview

- `raw/behavior/`
  - Per-subject main-task behavioral CSV files.
  - Current repository layout contains 44 behavioral files.

- `raw/eye_tracking/`
  - Raw EyeLink `.asc` files for the main eye-tracking task.
  - These files are gitignored because of their size and may be absent in a fresh clone.
  - The current local project layout contains 43 eye-tracking files; `X38.asc` is absent while `raw/behavior/38.csv` is present, so eye-tracking analyses use one fewer participant than behavioral analyses.

- `rating_data/`
  - Per-subject supplementary rating-task CSV files (`sub-{ID}/ratings.csv`).
  - Current repository layout contains 20 supplementary rating participants.

- `stimuli/stimulus_config.csv`
  - Stimulus definitions used by the main task and supplementary rating task.

- `processed/`
  - Processed outputs used by downstream analyses.
  - `behavior_summary.csv` is generated by `analysis/01_preprocess_behavior.py`.
  - `eye_metrics_all_subjects.csv`, `eye_metrics_subject_means.csv`, and `gaze_analysis_all_subjects.RData` are generated by `analysis/03_gaze_pipeline.R` when raw eye-tracking files are available.
  - `judgment_*.csv` files are generated by `analysis/independent_rating_analysis.R`.

## Provenance notes

- Some raw files contain historical absolute paths recorded on the original collection or conversion machine (for example, `StimuliFile` in supplementary rating data, or conversion headers inside `.asc` files).
- These embedded paths are provenance metadata only. The current analysis scripts use repository-relative paths and do not depend on those historical machine-specific paths.
